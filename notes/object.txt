Interfaces------------------------------------------------------------------------------------------
An interface is a contract that defines what a class should do, not how it does it.
It contains:
Method declarations
Property declarations
Events
Indexers
❌ No method body (before C# 8)
❌ No instance fields
-C# does not allow multiple inheritance with classes, but it allows it with interfaces.
✔ Cannot create object of interface
✔ A class can implement multiple interfaces
✔ All members are public by default
